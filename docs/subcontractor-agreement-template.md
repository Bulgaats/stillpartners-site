# Subcontractor Agreement Template Notes

This app should present the agreement before first worker access and store:

- agreement version
- signature name
- signature timestamp
- signer IP address where available
- generated PDF path in Supabase Storage

## Required Independent-Contractor Wording

Use lawyer-reviewed wording before production. A practical draft clause for the
application workflow is:

> I acknowledge that I am engaged by Still Partners Pty Ltd as an independent contractor and not as an employee. I am responsible for my own Australian tax, ABN, insurance, tools where applicable, and compliance obligations unless a written agreement states otherwise.

## Production Risk

Calling a worker an independent contractor does not by itself make the
relationship compliant under Australian tax, superannuation, workers
compensation, sham contracting, or employment law. The agreement, onboarding
flow, work practices, payment model, insurance requirements, and site control
model should be reviewed by a qualified Australian lawyer and accountant.
